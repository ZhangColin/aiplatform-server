## 架构落点（ADR-0002 双轨分野）

- 新 base 分区 `base.chatagent`（第七个 BC，GENERIC），与 `base.agentengine` 分立起步——编码引擎路径零改动（本票未触碰 agentengine 任何文件）。
- 端口 `ChatAgentClient.converse(command, progress)`：文本增量经 `ChatAgentProgress.onTextDelta` 回调；计量按命令 `UsageContext`（subject/dims 调用方可配）上报，幂等键 `chat-usage-{runId}`（对齐 opencode 的 `agt-usage-{runId}` 先例）。
- 用量口径：AgentScope `ModelCallEndEvent.getUsage()`（inputTokens 含缓存、cachedTokens 为子集）→ 计量域既有 `TokenUsage.fromOpenAiProtocol`（input = prompt − cached）；ReAct 多迭代五桶累积，对话结束恰报一条；无归属不报、零用量不报。
- `HarnessAgent` 经工厂按规格缓存复用（agent 无状态、per-session 寻址靠 RuntimeContext），容器关闭统一释放；`agentscope.state.home` 与 workspace 在测试中定向临时目录。
