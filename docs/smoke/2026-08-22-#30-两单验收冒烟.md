## 3. 测试外包循环（第一单）

一轮完整循环全通：

1. dev 建测试任务指派 OPC（本账号）→ 期 DEV→TEST 自动推进；opc 待办亮 NEW_TASK
2. OPC start/submit（预览实测发现 2 个真实 Bug：GitHub 占位链接 sev3 / favicon 404 sev4）；dev 待办亮 TASK_SUBMITTED
3. dev confirm → 事务内 Bug 入库 OPEN×2 + TEST_REPORT/BUG 素材入库 + **修复链自动派发**
4. 修复链串行执行（逐 Bug 一 run 一新会话，role=DEV/计量 dims role=FIX）：Bug1 17:21:11→17:21:54 FIXED；Bug2 修复两次才翻 FIXED（**异常插曲，见 §7-②**）
5. 修复真实生效（链接改 `https://github.com/colin`、favicon.ico 200）；dev 待办亮 RETEST_READY
6. **G3 谓词核验**：Bug 仅 FIXED 未 VERIFIED 时 approve → 409「开发完成确认未通过：项目存在未关闭 Bug」✓
7. 复测任务 → 逐条 pass → confirm → 两 Bug VERIFIED → G3 ready=true → approve 过门

非法迁移 409 守门实测：重复 confirm → 409；未提交驳回 → 409；已提交取消只能驳回（状态机口径）✓（注意 §7-④ 消息模板问题）。

## 7. 遗留清单

### 高危（建议「真痛」成票）

**① PERMISSION 等待点平台全盲——run 静默卡死 30 分钟**
- 现象：opencode 权限挂起（本冒烟中两次均为 agent 读 `/workspace/.env` 触发 ask 规则）平台不检出，waits 列表为空，run 卡到 `timeout-minutes=30` 才以超时收口。两次复现（第一单 DEV run、第二单修复 run），均靠**绕过平台直批引擎**恢复（`POST /session/{id}/permissions/{id} {"response":"once"}`）。
- 排查事实：引擎侧 **`GET /permission` 列表端点实测存在**（watcher 注释「无列表端点可轮询」不成立）；事件总线手动订阅健康（90s 收 2046 帧，含 message.part.delta/tool 等）；`permission.updated` 帧为何未被 watcher 捕获未定性（JDK HttpClient `timeout+ofLines` 组合有嫌疑；重连退避只打 debug 不可见）。
- 建议：watcher 补 `/permission` 轮询通道（与问答轮询同构，最稳）或修复总线路径；补一条「权限挂起 → 平台 wait → settle 批准/拒绝」的端到端测试。顺带评估：`.env` 读权限 ask 规则对 agent 日常探索过于易感（两次 run 都撞），可考虑引擎配置收紧。

### 中（建议成票/复查）

**② 修复链乐观翻转被拒后同一 Bug 修了两次（根因未定位）**
- 实录：favicon Bug 的 fix run（727555）正常跑完 31 步、修复真实生效，但终态到达时 `markFixed` 守卫不满足被 WARN 拒（「已离开 OPEN/标记已换」）；链随即以 OPEN∧fixRunId NULL 重新派发（62938），后者发现「工作区中已存在修复」后翻 FIXED。净效果 = 重复修复一次（A4「重跑=无害冗余」哲学兜住，无误翻无链断），但 `markFixDispatched` 落库标记与终态判定之间为何不一致（17:21:54→17:25:35 之间标记丢失）未定位。建议：补「两 Bug 串行链」集成测试复现；候选方向——并发写覆盖 / 事件重投 / save 生效时机。

### 低（顺手记录）

**③ preview-ready 由 `GET /preview` 懒触发**：Demo run 完成不自动发事件；首次调 preview 端点才暴露端口并发 SSE（本冒烟中 Demo 完成 09:43:34，事件 09:52:19 随首次 GET 而来）。与 A3 §2.3「完事 preview-ready」措辞有出入（B0 checklist 以 GET 为准）。前端若靠事件亮预览按钮会不亮——**fog 候选**（真痛再加）。

**④ 409 响应消息模板未渲染**：任务非法迁移的 HTTP 响应 message 为字面量「任务状态不允许该操作（{0} → {1}）」（服务端 WARN 日志渲染正常；门 409 消息渲染正常）。疑 TASK_ 消息参数传递问题——**fog 候选**。

**⑤ 用量 unpriced 档**：deepseek v4-pro/flash 的 reasoning 档无单价行（`met_price_entries` 种子缺），usage 响应 unpriced 如实暴露。关心推理成本则补单价行——**fog 候选**。

**⑥ 环境遗留**：a) 冒烟前即存在两组无属主工作区容器（DB 无对应项目行），疑历史清理遗漏，未动，待确认后 `docker rm`；b) `prj_projects` 列表过滤参数有 archived 位，本次未单独验证归档（归档=单向终点，v1 口径明确，留给后续）。
